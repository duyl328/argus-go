# 虚拟滚动调试面板使用指南

## 🎯 快速开始

### 访问调试面板

1. **启动开发服务器**
   ```bash
   npm run dev
   ```

2. **打开浏览器**
   - 访问: http://localhost:3001
   - 导航到: **文件夹** (FieldView) 页面

3. **打开调试面板**
   - 右下角会显示绿色🔬按钮
   - 点击按钮打开调试面板

---

## 🎮 调试面板功能

### 1. 测试数据生成器

#### 预设按钮
- **100** - 基础功能测试
- **500** - 虚拟滚动启用临界点
- **1K** - 常规使用场景
- **5K** - 大量文件场景
- **1W** - 极限测试
- **5W** - 压力测试

#### 自定义数量
1. 在输入框输入文件数量（10-100000）
2. 点击"生成测试数据"按钮

#### 生成内容
- 📁 文件夹: 10%
- 🖼️ 照片: 70% (.jpg文件)
- 🎬 视频: 20% (.mp4文件)

---

### 2. 性能指标监控

调试面板实时显示以下指标：

#### 基础指标
- **总文件数**: 当前文件夹的文件总数
- **渲染DOM数**: 实际渲染的DOM节点数
- **DOM节约率**: 虚拟滚动节省的DOM百分比

#### 虚拟滚动状态
- **虚拟滚动**: 是否启用（>100文件自动启用）
- **视图模式**: 网格/列表
- **缩放级别**: 当前缩放百分比

#### 滚动信息
- **滚动位置**: 当前滚动条位置(px)
- **开始索引**: 渲染的第一个文件索引
- **结束索引**: 渲染的最后一个文件索引
- **总高度**: 虚拟滚动容器总高度(px)
- **列数**: 网格模式的列数

---

- 快速跳转到文件列表顶部

- 快速跳转到文件列表底部

## 🐛 问题排查

### 调试面板不显示

**原因**: 仅在开发环境显示

**解决方案**:
```bash
# 确认是开发模式启动
npm run dev

# 而不是
npm run build && npm run preview
```

### 测试数据生成失败

**可能原因**: 输入数量超出范围

**解决方案**:
- 确保输入10-100000之间的数字
- 对于超大数量（>50000），可能需要等待几秒

### 性能指标不更新

**解决方案**:
1. 关闭调试面板
2. 重新打开
3. 刷新页面
