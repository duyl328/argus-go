# 🚀 文件管理器快速开始

## 一、启动服务

### 1. 启动后端 (必需)

```bash
cd D:\go-argus\src\rear
go run main.go
```

✅ 看到以下信息表示后端启动成功:
```
服务器启动成功: http://localhost:9484
```

### 2. 启动前端

```bash
cd D:\go-argus\src\front\argus-front
npm run dev
```

✅ 看到以下信息表示前端启动成功:
```
VITE ready in xxx ms
➜  Local:   http://localhost:3000/
```

## 二、访问文件管理器

打开浏览器访问: **http://localhost:3000/field**

## 四、常见问题

### Q1: 页面显示空白或加载失败?

**检查后端是否启动**
```bash
# 测试后端 API
curl http://localhost:9484/api/v1/filesystem/browse
```

应该返回驱动器列表的 JSON 数据。

### Q2: 显示 "无法打开文件夹"?

可能原因:
1. 权限不足 (某些系统文件夹需要管理员权限)
2. 路径不存在
3. 后端服务未响应

### Q3: 如何切换到 Mock 数据模式?

1. 点击右下角 🔬 按钮打开调试面板
2. 找到"🔌 API 集成"部分
3. 点击"切换到 Mock 数据"

### Q4: 如何查看 API 请求?

1. 打开浏览器开发者工具 (F12)
2. 切换到 Network 标签
3. 筛选 XHR 请求
4. 查看 `/api/v1/filesystem/` 开头的请求

## 五、开发模式

### 修改 API 基础 URL

编辑 `.env` 文件:
```env
VITE_APP_API_URL=http://127.0.0.1:9484/api
```

### 禁用真实 API (测试 Mock 数据)

编辑 `src/views/FieldView.vue`:
```vue
<!-- 改为 false 使用 Mock 数据 -->
<FileManager :use-real-api="false" />
```
