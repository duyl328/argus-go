# 文件类型支持说明

## 概述

Argus 照片管理系统专注于照片和视频的管理，支持常见的图片和视频格式。对于不支持的文件类型，会显示其文件扩展名。

## 支持的文件类型

### 📸 图片格式

#### 常见格式
- **JPEG/JPG** - 最常见的照片格式
- **PNG** - 支持透明的图片格式
- **GIF** - 动图格式
- **BMP** - 位图格式
- **WEBP** - Google 开发的现代图片格式
- **SVG** - 矢量图格式

#### RAW 格式（专业相机）
- **CR2/CR3** - Canon RAW
- **NEF** - Nikon RAW
- **ARW** - Sony RAW
- **DNG** - Adobe Digital Negative
- **ORF** - Olympus RAW
- **RW2** - Panasonic RAW
- **PEF** - Pentax RAW
- **SRW** - Samsung RAW
- **RAF** - Fujifilm RAW

#### 高级格式
- **TIFF/TIF** - 无损图片格式
- **HEIC/HEIF** - iOS 照片格式
- **AVIF** - 新一代图片格式
- **JXL** - JPEG XL 格式

### 🎬 视频格式

#### 常见格式
- **MP4** - 最常见的视频格式
- **AVI** - 微软视频格式
- **MOV** - QuickTime 视频格式
- **MKV** - 高清视频容器
- **WMV** - Windows Media Video
- **FLV** - Flash 视频
- **WEBM** - Web 视频格式
- **M4V** - iTunes 视频格式

#### 高清格式
- **MTS/M2TS/TS** - AVCHD 高清视频

#### 其他格式
- **3GP** - 手机视频格式
- **MPG/MPEG** - MPEG 视频
- **VOB** - DVD 视频
- **OGV** - Ogg 视频
- **RM/RMVB** - RealMedia 视频
- **ASF** - Advanced Systems Format

## 文件类型识别逻辑

### 识别优先级

1. **MIME 类型** (后端提供)
   - 最准确的文件类型识别
   - 基于文件内容而非扩展名

2. **文件扩展名**
   - MIME 类型无法识别时使用
   - 基于文件名后缀判断

### 类型分类

```typescript
// 文件夹
type: 'folder' → 📁

// 照片
type: 'photo' → 🖼️

// 视频
type: 'video' → 🎬

// 不支持的文件
type: 'file' → 显示扩展名 (例如: TXT, ZIP, PDF)
```

## 显示样式

### 网格视图

**支持的文件**
- 文件夹: 📁 大图标，橙色
- 照片: 🖼️ 大图标，蓝色
- 视频: 🎬 大图标，粉色

**不支持的文件**
- 样式: 灰色背景，边框，显示扩展名
- 示例: `TXT`, `ZIP`, `PDF`, `DOC`
- 字体: 11px, 粗体, 大写

### 列表视图

**支持的文件**
- 文件夹: 📁 20px
- 照片: 🖼️ 18px
- 视频: 🎬 18px

**不支持的文件**
- 样式: 小标签样式，灰色背景
- 字体: 10px, 粗体, 大写
- 最小宽度: 28px

### 前端转换

```typescript
// 优先使用 MIME 类型
if (item.file_info.mime_type) {
  itemType = getFileTypeByMime(item.file_info.mime_type)
}

// MIME 无法识别时使用扩展名
if (itemType === 'file' && item.file_info.extension) {
  itemType = getFileTypeByExtension(extension)
}
```

## 统计功能

### 文件统计

在面包屑导航右侧显示当前文件夹的统计信息:

```
🖼️ 128  (照片数量)
🎬 15   (视频数量)
```

**统计逻辑**
```typescript
const fileStats = computed(() => {
  const items = visibleItems.value
  return {
    photos: items.filter(item => item.type === 'photo').length,
    videos: items.filter(item => item.type === 'video').length
  }
})
```

**注意**: 只统计照片和视频，不统计其他文件类型

## 工具函数

### `getFileTypeByExtension(extension: string)`
根据扩展名判断文件类型

```typescript
getFileTypeByExtension('jpg')   // 'photo'
getFileTypeByExtension('mp4')   // 'video'
getFileTypeByExtension('txt')   // 'file'
```

### `getFileTypeByMime(mimeType: string)`
根据 MIME 类型判断文件类型

```typescript
getFileTypeByMime('image/jpeg')  // 'photo'
getFileTypeByMime('video/mp4')   // 'video'
getFileTypeByMime('text/plain')  // 'file'
```

### `isSupportedMediaFile(extension: string)`
判断是否为支持的媒体文件

```typescript
isSupportedMediaFile('jpg')   // true
isSupportedMediaFile('mp4')   // true
isSupportedMediaFile('txt')   // false
```

### `getFileIcon(type: FileType, extension?: string)`
获取文件图标或扩展名显示

```typescript
getFileIcon('folder')           // '📁'
getFileIcon('photo')            // '🖼️'
getFileIcon('video')            // '🎬'
getFileIcon('file', 'txt')      // 'TXT'
getFileIcon('file', 'pdf')      // 'PDF'
getFileIcon('file')             // '📄' (无扩展名)
```

## 扩展指南

### 添加新的图片格式

1. 编辑 `src/config/fileTypes.ts`
2. 在 `IMAGE_EXTENSIONS` 数组中添加扩展名
3. 如果需要，在 `MIME_TYPE_MAP` 中添加 MIME 映射

```typescript
export const IMAGE_EXTENSIONS = [
  // ... 现有格式
  'jxl',  // 新格式
  'avif'  // 新格式
]

export const MIME_TYPE_MAP = {
  // ... 现有映射
  'image/jxl': 'photo',
  'image/avif': 'photo'
}
```

### 添加新的视频格式

同样的流程，修改 `VIDEO_EXTENSIONS`:

```typescript
export const VIDEO_EXTENSIONS = [
  // ... 现有格式
  'av1',  // 新格式
]
```

### 自定义文件类型图标

修改 `getFileIcon` 函数:

```typescript
export function getFileIcon(type: FileType, extension?: string): string {
  switch (type) {
    case 'file':
      // 可以为特定扩展名定制图标
      if (extension === 'pdf') return '📕'
      if (extension === 'zip') return '📦'
      return extension ? extension.toUpperCase() : '📄'
    // ... 其他类型
  }
}
```

## 性能考虑

### 类型判断缓存

对于大量文件，类型判断已经优化:

1. **一次判断**: 在 `convertToFileItem` 中完成
2. **结果缓存**: 存储在 `FileItem.type` 中
3. **扩展名预处理**: 提前提取并存储

### 统计计算

文件统计使用 computed 属性，只在数据变化时重新计算。

## 常见问题

### Q: 为什么某些图片显示为普通文件?

**可能原因**:
1. 扩展名不在支持列表中
2. 后端未正确识别 MIME 类型
3. 文件扩展名大小写问题 (已自动处理为小写)

**解决方法**:
- 检查 `IMAGE_EXTENSIONS` 是否包含该扩展名
- 添加缺失的扩展名到配置

### Q: 如何自定义不支持文件的显示?

编辑 `src/components/FileManager/FilePane.vue` 的样式:

```css
.file-item[data-item-type="file"] .file-icon {
  /* 修改样式 */
  background: #your-color;
  font-size: 12px;
}
```

### Q: 能否添加文档类型的特殊处理?

可以扩展 `FileType` 类型:

```typescript
// types.ts
export type FileType = 'folder' | 'photo' | 'video' | 'document' | 'file'

// fileTypes.ts
export const DOCUMENT_EXTENSIONS = ['pdf', 'doc', 'docx', 'txt']

// 添加判断逻辑
if (DOCUMENT_EXTENSIONS.includes(ext)) {
  return 'document'
}
```
