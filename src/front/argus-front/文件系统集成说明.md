# 文件系统 API 集成说明

## 概述

已成功将前端文件管理器与后端文件系统 API 集成。前端可以通过 API 访问真实的文件系统,包括浏览文件夹、创建目录、删除文件等操作。

## 集成内容

### 1. 新增文件

#### `src/services/fileSystemService.ts`
文件系统 API 服务层,提供以下功能:
- `browse(path)` - 浏览文件系统
- `getDiskUsage(path)` - 获取磁盘使用情况
- `getItem(path)` - 获取文件系统项目信息
- `searchFiles(path, pattern, type, recursive)` - 搜索文件
- `createDirectory(path)` - 创建目录
- `deleteItem(path, operationId, recursive)` - 删除文件或目录
- `moveItem(source, destination, operationId, overwrite)` - 移动/重命名
- `copyItem(source, destination, operationId, overwrite)` - 复制

#### `src/composables/fileManager/useFileSystemAPI.ts`
文件系统 API Composable,用于在组件中集成:
- 状态管理: `currentPath`, `items`, `loading`, `error`
- 转换函数: `convertToFileItem` (后端格式 → 前端格式)
- 所有 CRUD 操作的封装

### 2. 修改文件

#### `src/components/FileManager/FilePane.vue`
- 添加 `useFileSystemAPI` 集成
- 添加 `USE_REAL_API` 开关(默认 false,使用 Mock 数据)
- 修改 `currentFolder` 计算逻辑,支持真实 API 和 Mock 数据
- 修改 `navigateToFolder` 函数,支持真实 API 导航
- 在 `onMounted` 中初始化真实 API(如果启用)
- 传递 API 状态给 DebugPanel

#### `src/components/FileManager/DebugPanel.vue`
- 添加"API 集成"部分
- 显示当前数据源(真实 API / Mock 数据)
- 显示 API 加载状态和错误信息
- 添加切换按钮,可在真实 API 和 Mock 数据间切换

## 后端 API 端点

基础 URL: `http://localhost:9484/api/v1`

### 浏览相关
- `GET /filesystem/browse?path={path}` - 浏览文件系统
- `GET /filesystem/disk-usage?path={path}` - 获取磁盘使用情况
- `GET /filesystem/item?path={path}` - 获取项目信息
- `GET /filesystem/search?path={path}&pattern={pattern}&recursive={bool}` - 搜索文件

### 操作相关
- `POST /filesystem/directory` - 创建目录
  ```json
  { "path": "/path/to/directory" }
  ```

- `DELETE /filesystem/item?path={path}` - 删除文件或目录

- `PUT /filesystem/item/move` - 移动/重命名
  ```json
  {
    "source": "/old/path",
    "destination": "/new/path",
    "overwrite": false
  }
  ```

- `POST /filesystem/item/copy` - 复制
  ```json
  {
    "source": "/source/path",
    "destination": "/dest/path",
    "overwrite": false
  }
  ```

## 数据格式

### 后端响应格式 (FileSystemItem)
```typescript
{
  id: string              // 唯一标识
  name: string            // 显示名称
  path: string            // 完整路径
  type: 'drive' | 'directory' | 'file'
  size: number            // 字节
  mod_time: string        // ISO 8601 时间
  is_accessible: boolean
  drive_info?: {          // 驱动器信息
    label: string
    total_space: number
    free_space: number
    usage_percent: number
  }
  file_info?: {           // 文件信息
    extension: string
    mime_type: string
  }
  directory_info?: {      // 目录信息
    item_count: number
  }
}
```

### 前端格式 (FileItem)
```typescript
{
  name: string
  type: 'folder' | 'photo' | 'video' | 'file'
  size?: string           // 格式化的大小字符串
  date?: string           // 格式化的日期字符串
  children?: Record<string, FileItem>
}
```

## 注意事项

1. **路径格式**: Windows 使用反斜杠 `\`,需要在 API 调用时正确处理
2. **权限问题**: 某些系统目录可能无权访问,需要处理权限错误
3. **大文件操作**: 复制/移动大文件时需要显示进度
4. **并发控制**: 避免同时进行多个修改操作
5. **错误处理**: 网络错误、权限错误等需要友好提示
