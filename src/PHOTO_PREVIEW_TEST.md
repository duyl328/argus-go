# 照片预览功能测试指南（v2 - macOS Quick Look 风格）

## ✅ 已实现的功能

### 后端
- [x] 预览 API: `GET /api/v1/photo/preview?path={path}&size={size}`
- [x] 智能格式转换（RAW → PNG → JPG/WebP）
- [x] 多级缩略图生成（720p / 2K / 原图）
- [x] 自动缓存机制

### 前端
- [x] **macOS Quick Look 风格预览窗口**（悬浮、圆角、半透明背景）
- [x] **文件列表中显示图片缩略图**（网格视图和列表视图）
- [x] 渐进式加载（缩略图 → 高清 → 原图）
- [x] 缩放和平移功能
- [x] 空格键快捷预览

## 🧪 测试步骤

### 1. 启动服务

#### 后端
```bash
cd D:\go-argus\src\rear
go run main.go
```

#### 前端
```bash
cd D:\go-argus\src\front\argus-front
npm run dev
```

### 2. 测试预览功能

1. **打开文件管理器**
   - 访问：http://localhost:3000/field

2. **浏览到包含照片的文件夹**
   - 双击进入文件夹
   - 确保文件夹中有 JPG/PNG/RAW 等图片文件

3. **测试缩略图显示**（新功能！）
   - 📸 **网格视图**: 照片文件应显示实际的缩略图，而不是图标
     - 小尺寸：60x60 像素缩略图
     - 中等尺寸：80x80 像素缩略图
     - 大尺寸：120x120 像素缩略图
   - 📋 **列表视图**: 照片文件图标处应显示 32x32 像素缩略图
   - 文件夹和其他文件类型仍显示图标

4. **测试 Quick Look 预览**（新风格！）
   - 点击选中一张照片（照片项会高亮）
   - 按下 **空格键**
   - 应该弹出 **macOS 风格的悬浮预览窗口**：
     - ✨ 圆角边框（12px）
     - 🌫️ 半透明背景（带模糊效果）
     - 📏 适中大小（85%视口，可以看到后面的文件列表）
     - 🎬  弹出动画（缩放 + 淡入）
   - 窗口包含三部分：
     - 顶部标题栏：文件名 + 文件大小 + 关闭按钮
     - 中间图片区域：可缩放、平移
     - 底部工具栏：缩放控制 + 质量切换

5. **测试预览交互**
   - **初始加载**: 应显示 720p 缩略图（加载快）
   - **双击放大**: 双击图片，自动放大并切换到高清模式
   - **滚轮缩放**: 鼠标滚轮缩放图片
   - **拖拽平移**: 放大后可拖拽图片查看细节
   - **质量切换**:
     - 点击底部"缩略图"按钮 → 720p
     - 点击"高清"按钮 → 2K 高清
     - 点击"原图"按钮 → 原图（可能很大）
   - **关闭预览**:
     - 按 ESC 键
     - 点击右上角关闭按钮（悬停时变红色）
     - 点击窗口外的背景区域

### 3. 测试不同文件格式

#### 小图片（< 5MB）
- 测试 JPG/PNG 小文件
- 预期：直接加载原图

#### 中等图片（5-20MB）
- 测试中等 JPG 文件
- 预期：初始加载 1080p 缩略图

#### 大图片（> 20MB）
- 测试专业相机拍摄的 RAW 或大 JPG
- 预期：
  1. 初始加载 720p 缩略图（< 200KB，快速）
  2. 切换到高清时加载 2K 版本（1-2MB）
  3. 切换到原图时才加载完整文件

#### RAW 格式
- 测试 CR2/NEF/ARW 等 RAW 文件
- 预期：后端自动转换为 JPG 并生成缩略图

### 4. 测试边界情况

- **路径错误**: 选中文件后手动删除，再预览
- **网络错误**: 断开后端服务，再预览
- **非照片文件**: 选中文件夹或视频，按空格
  - 预期：文件夹/其他文件使用旧的 QuickPreview
  - 仅照片使用 PhotoPreviewModal

## 🎯 预期表现

### 性能指标
- **初始预览响应**: < 500ms（包括 Hash 计算）
- **缩略图加载**: < 200ms（720p < 200KB）
- **高清加载**: < 1s（2K 约 1-2MB）
- **原图加载**: 取决于文件大小，应显示加载进度

### 用户体验
- **渐进式加载**: 先模糊后清晰，不阻塞操作
- **平滑缩放**: 缩放和平移动画流畅
- **快捷键**: 空格预览，ESC 关闭，+/- 缩放
- **智能提示**: 底部控制栏显示当前质量和文件信息

## 🐛 已知问题与限制

1. **首次预览延迟**
   - 问题：Hash 计算可能需要几百毫秒
   - 解决：后续可优化为异步计算

2. **大文件内存占用**
   - 问题：加载 40MB 原图可能占用大量内存
   - 解决：用户需明确点击"原图"才加载

3. **视频不支持**
   - 当前仅支持照片预览
   - 视频预览将在未来版本实现

## 🔧 调试技巧

### 查看网络请求
1. 打开浏览器开发者工具（F12）
2. 切换到 Network 标签
3. 预览照片，观察请求：
   - `/api/v1/photo/preview?path=...&size=720` → 缩略图
   - `/api/v1/photo/preview?path=...&size=2048` → 高清
   - `/api/v1/photo/preview?path=...&size=0` → 原图

### 查看控制台日志
- 前端错误会显示在 Console 标签
- 后端日志在终端输出

### 检查文件生成
- 缩略图缓存位置：`D:\go-argus\src\rear\thumbnail\{hash前4位}\{hash}\{size}.jpg`
- 检查是否生成了对应尺寸的缩略图
